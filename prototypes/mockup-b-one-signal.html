HOW THIS DIRECTION WORKS

One particle field is the whole site. Nothing decorative.

Semantic honesty

Every formation is built from real geometry — his face sampled from the actual portrait, seam curves from a regulation ball, colony scatter from wetlab imagery described in text, a valve ring for the clinical work. If a dot can't justify itself, it's cut.

Abstraction hands off to evidence

The field never replaces proof. Each chapter's glyph decomposes into a real capture — in-headset footage, stills, shipped film frames. Dots make the argument; media closes it.

Comfort mode is a feature

Reduced-motion swaps live particles for pre-rendered stills of the same formations. Headset work taught him to ship comfort modes; the site wears that discipline visibly.
