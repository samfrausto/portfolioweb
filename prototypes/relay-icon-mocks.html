MOTION SPEC — ONE PARAGRAPH

One swarm, four resolves, zero physics. The existing hero-exit tween keeps its start: at the hero threshold the 9,000-dot identity peels off exactly as it does today, but instead of freezing into the placeholder line, ~1,500 "carrier" dots stay live for the whole Selected Systems scroll (the rest fade out mid-flight as density donors). Each card owns a scroll window derived from its viewport entry — inside it, every carrier dot runs a deterministic per-dot tween from its position in the previous icon to its sampled target in the next one: eased in/out, horizontally-biased mid-flight scatter (datacurve streaming, never radial bursts, never path-following tails), per-dot delay hashed from index so the icon dissolves and re-knits edge-first. Scrubbing backwards runs the identical tween in reverse. Icons resolve beside each card's media panel; on SYS 01 and SYS 02 the final 10% of resolve cross-fades the icon into the card's live glyph canvas (loop / valve) which is already drawing underneath, so the dots literally hand the story to the instrument.
