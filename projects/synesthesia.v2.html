Synesthesia

Adjustable surroundings for a Vision Pro workspace.

From a scene to something you can control

The project
An ambient environment behind the user's workspace, with adjustable scenes, color, music, and opacity.
My role
Technical lead. I handled the Unity implementation and used AI to write C# scripts. My teammates created the visual design and models.

Connecting the controls to the environment

Two sliders control the top and bottom colors of the sky. The C# controller converts each slider's position into a color and passes it to the gradient material, so the environment changes as the controls move.

Scene buttons switch between the base, country, jazz, and EDM environments. The scene controller coordinates the selected environment, its music, and the button highlight. Color controls appear in the base scene and hide in the themed scenes.

The implementation uses Unity PolySpatial's sample spatial controls, connected through AI-assisted C# scripts. I did not build the underlying SDK controls from scratch.

Getting the shading working with the SDK

The hardest parts were getting the color shading to work with the VR SDK and navigating the Unity-to-visionOS workflow. I used the SDK manuals to troubleshoot the integration.

My work combined hands-on Unity setup with AI-assisted C# coding and documentation-led troubleshooting to bring the team's scenes and controls into a working prototype.

A working spatial prototype

The prototype brings scene switching, adjustable color, music, and opacity into one visionOS experience. The recording above shows the scene and color controls in the simulator.
